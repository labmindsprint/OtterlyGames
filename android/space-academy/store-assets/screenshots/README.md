All files are PNG, 1080x1920 (9:16), under 1 MB each. They were captured from the real game (Class 2 "Twin Shuttle") at a 360x640 viewport, device scale factor 3, touch and mobile emulation. The `?test` debug toast is hidden.

## Known limitations
At 360x640 the lab map and the "You found it!" screen overlap text, so they are not included. This is a layout issue in the app, not in the screenshots. Roam screenshots show a thin light frame at the screen edge, which comes from the app.
