How to run a mock test at home

  1. Practise chapters first. Do not start with a paper before the topics feel familiar. Use the chapter practice.
  2. Do one untimed paper. Let your child use hints and read the worked answers afterwards.
  3. Add a timer later. When the untimed paper feels easy, set a generous timer on a phone. Shorten it gradually.
  4. Review mistakes together. Group them: misread the question, forgot a method, or ran out of time. Practise the matching chapter.

Keep sessions calm. A mock test is a practice tool, not a verdict.

Frequently asked questions

Are these real past olympiad papers?

No. Every question is original Otterly practice. They are not copies of any organiser’s paper and are not official.

Is the practice paper timed?

No. For a timed mock test, set a timer yourself once your child is confident.

Does a mock test predict the real result?

No. Practice shows which topics feel comfortable and which need more time. It is not a score prediction or a rank.

Where is the syllabus?

Check the organiser’s current syllabus. See IMO preparation for the topics Otterly practises in each class.
