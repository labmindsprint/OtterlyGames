How to Use a Multiplication Table

A multiplication table is one of the most powerful learning tools in primary maths. To find the answer to any times-table fact, locate one number along the top and the other down the left side. Where the row and column meet is the product.

This interactive chart lets you tap a number to highlight its entire table, making patterns easy to spot. Try highlighting the 9× table and watch how the tens digit goes up while the ones digit goes down!

Patterns to Look For

The table is symmetrical along the diagonal — because multiplication is commutative (3 × 8 = 8 × 3). That means children only need to learn roughly half the facts, since each one has a mirror partner.

The 2× column is even, and the 5× column ends in 0 or 5. From 9×1 through 9×10, the product's digits add up to 9. That last shortcut needs care with larger products: 9×11 is 99, whose digits add up to 18.

Frequently Asked Questions

What is a multiplication table?

A times-table chart is a grid of products. This chart uses numbers 1 to 12. Where a row and column meet, the cell shows their product.

How do you read a multiplication table?

Find one number along the top and the other down the side. Row 7 and column 8 meet at 56, so 7 × 8 = 56.

What patterns can you find in a times-table chart?

The 2× column is even, the 5× column ends in 0 or 5, and the grid is symmetrical because 3 × 8 equals 8 × 3. From 9×1 through 9×10, product digits add up to 9; 9×11 is 99, whose digits instead add up to 18.
