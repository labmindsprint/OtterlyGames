    OTTERLY GAMES · FOR CHECKING TOGETHER

    Answer key

      Match the activity and sheet seed before checking. A shared link starts with the answer key hidden.

      Use a sheet as a starting point, not a test

      Choose fewer when helpful

      Start with five questions and stop when you have something to discuss. A fixed times table, divisor or whole-hour clock has 12 unique questions. Five-minute clocks have 144 possible times, so a 20-question sheet can also avoid repeats.

      Check the idea, not the speed

      Use the times-tables, division or telling-time path for a worked example. Division sheets use exact positive whole-number answers only. Clocks use 12-hour faces without AM or PM.

      Keep the same questions

      Build with a chosen seed to return to a sheet, or use Generate fresh sheet for a new seed. The link contains only the activity, table or clock step, question count and seed. It does not store completed answers or create an account. Opening the page still makes a normal request to the website host.
